# 丞丞学习基地

给二年级孩子丞丞做的学习工具主页。当前采用用户选定的「乐园地图」方向，入口清楚、有一点探索感，但不是家长后台。

## 直接打开

打开 `index.html` 即可使用：

- 英语记忆乐园：单词卡、英语小镇、补充练习、声音试听
- 汉字探险岛：按年级选字、查笔顺、看组词和造句
- 数学小火车、阅读故事屋：保留入口，标记为准备中

## 当前结构

```text
learning-hub/
  index.html          丞丞主页
  tools/english/      英语工具副本
  tools/hanzi/        汉字工具副本
```

两个工具都已加入统一导航，可以随时回到丞丞主页，也可以在英语和汉字之间切换。原始工具目录没有修改。

## 已验证

- 桌面 1440 x 900、手机 375 x 812 渲染
- 主页进入英语、汉字及返回主页
- 英语四个页面之间的导航
- 汉字查字页和年级选字入口
- 控制台错误与横向溢出检查
